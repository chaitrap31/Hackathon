# ApplyIt

### Moving K-12 Education from Rote Learning to Tactile Application

> **Hackathon Track:** K-12 Education — Moving from Rote Learning to Application  
> **Problem Statement Challenge:** Turn textbook concepts into meaningful real-world learning experiences, encourage experimentation and critical thinking, work in typical classrooms with zero-cost/low-cost materials, and evaluate conceptual understanding beyond written exams using Bloom's Taxonomy.

---

## 🌟 Why ApplyIt Wins

| Challenge in Problem Statement         | How ApplyIt Solves It                                                                                                                                                                                                                         |
| -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Rote Memorization Trap**             | Replaces rote definitions with immersive real-world crisis narratives (e.g. logistics warehouse ramp, Mars colony greenhouse, municipal blackout grid).                                                                                       |
| **Limited Classroom Time (45 mins)**   | Engineered into structured **15-minute micro-activities** (2 min hook + 10 min investigation + 3 min reflection) that easily fit inside standard school periods.                                                                              |
| **Inadequate Resources / Lack of Lab** | **Zero-Cost Kit Directory**: Every activity uses ₹0 classroom scrap (rulers, turmeric, erasers, plastic bottles, water bags, foil) as direct substitutes for costly lab apparatus.                                                            |
| **Lack of Practical Assessment Tools** | **Real-Time Observation Grid**: Teachers tap student team evaluations during classroom walk-arounds using Bloom's Taxonomy rubrics (Remember → Understand → Apply → Analyze → Evaluate → Create) with instant printable session report cards. |
| **Syllabus / Topic Coverage**          | **AI Mission Generator**: Input any NCERT or state syllabus chapter + available scrap items, and generate a customized hands-on mission with rubric in seconds.                                                                               |

## 🚀 Key Features

1. **Mission Library**
   - **Physics:** Friction & Surface Resistance (_The Warehouse Crisis_), Series vs Parallel Circuits (_The Municipal Blackout_), Acoustic Frequency (_The Soundstage Challenge_)
   - **Biology:** Photosynthesis & Limiting Factors (_The Mars Colony Farm_)
   - **Chemistry:** Acids, Bases & Organic Litmus (_The Food Safety Lab_)
   - **Geography / EVS:** The Water Cycle (_The Drought Response in a Ziplock_)

2. **Interactive Digital Twin Simulators**
   - High-performance, canvas-based and SVG-based physics twins that allow students to validate their physical classroom scrap results on screen.

3. **AI Mission Generator**
   - Enter any topic (e.g., "Density & Buoyancy", "Newton's 3rd Law") and select available scrap materials. Generates a complete 15-minute lesson plan, real-world narrative, instructions, and Bloom's rubric.

4. **Zero-Cost Kit Directory**
   - Curated directory showing Indian and typical school teachers how to replace ₹10,000+ of glass beakers, litmus paper, and tuning forks with ₹0 household items.

5. **Live Classroom Walkaround Assessment**
   - Real-time observation checklist.
   - Team gamification & points.
   - Depth-of-knowledge evaluation based on Bloom's Taxonomy.
   - One-click printable PDF Session Report Card.

6. **Parent Prep WhatsApp Dispatch**
   - Generates night-before messages in English, Kannada (ಕನ್ನಡ), and Hindi (हिंदी) so students bring ₹0 scrap items from home.
   - 1-click WhatsApp broadcast and printable physical circular slips.

7. **Multilingual Interface (English · ಕನ್ನಡ · हिंदी)**
   - Instant language switching across the entire platform.

8. **100% Client-First Architecture (Zero Backend Required)**
   - All state, sessions, custom missions, and metrics persist seamlessly in `localStorage`.
   - Zero database setup, zero server cold starts, 100% offline-capable, and immediately deployable to GitHub Pages, Vercel, or Netlify.

## 🛠️ Tech Stack

- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 (Classy, minimalist aesthetic with bespoke typography & subtle neutral tones)
- **Icons:** Lucide React
- **Routing:** React Router v7
- **Persistence:** Client-side local storage engine with automated demo seeders
